# Project

## Summary

Ny-drive is a browser-based isometric 3D driving sandbox centered on a one-to-one drivable recreation of New York City's public road network across all five boroughs. The project prioritizes geographically accurate roads, intersections, grades, bridges/tunnels, and real-world scale, while using simplified/procedural scenery so the browser can stream the city efficiently. The initial experience is intentionally narrow: one GC8-era late-1990s Subaru Impreza WRX STI-style car, physics-driven arcade/simulation handling with controllable drifting and handbrake use, open roads, and no traffic, pedestrians, missions, or progression.
